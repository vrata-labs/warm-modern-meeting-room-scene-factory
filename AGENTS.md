# Project Contract

- This repository is dedicated only to the warm-modern meeting-room A/B experiment and pilot Scene Factory.
- Do not add scene source files, release GLB files, previews, textures, or another room project.
- Each candidate scene lives in its own repository. Integrate only through full commit SHA and SHA-256 lock records.
- Candidate numbers are neutral. Do not record the curated/AI assignment in public shared files before the blind-review mapping is closed.
- Do not add model inputs or generated outputs until the human rights owner has approved the exact model, weights, dependencies, provider terms, retention, territories, and output redistribution.
- Do not start Stage 3 compiler implementation until the AI feasibility gate is green.
- Use ASCII for repository files unless a source record requires otherwise.
- Run `pnpm validate && pnpm test` before commit and push.
